# Concurrence

## Concurrents directs

- **Habitica** : RPG, XP/or, classique, gros mais vieux UX
- **LifeUp** : ultra-customisable, XP/coins/loot, focus solo
- **Lion XP** : MMORPG, raids, chat, leagues 48h, monétisation agressive
- **Solo Quest XP** : 3 quêtes/jour, 6 stats, rangs E→S (inspiré Solo Leveling)
- **KUBBO** : construction ville médiévale
- **LifeRank** : Bronze→Diamond, freemium
- **Fearless** : focus santé mentale
- **SuperBetter** : recovery santé
- **GamifyRoutine** : pomodoro + XP

## Ce qui manque chez TOUS

1. **Preuve réelle (photo/vidéo + IA)** → aucun ne vérifie vraiment, tout est auto-déclaré
2. **Classement géolocalisé** (ville/pays/monde)
3. **Compétition hebdo synchronisée** avec récompenses réelles
4. **Tâches civiques/altruistes** (SDF, vote, déchet ramassé)
5. **Authenticité sociale** → triche = jeu mort

## Ton différenciateur

→ **Le SEUL avec vérification = le SEUL crédible**
→ Pas un to-do list gamifié, un **réseau social de l'auto-amélioration prouvée**
→ Positionnement : "BeReal × Habitica × Strava"

## Risques concurrentiels

- Habitica gratuit + open source = base utilisateurs
- Lion XP / Solo Quest = même esthétique RPG, déjà installés
- Tu dois **éviter le piège RPG médiéval** → grand public, pas niche gamer
