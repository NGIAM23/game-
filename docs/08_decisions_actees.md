## Implications fortes

### Cible jeunes 16-25 → conséquences
- App store ratings 12+ (sinon perte 30% acquisition)
- Pas de chat ouvert pour <16 ans (RGPD-K)
- Design : sobre premium MAIS energie/dopamine (Duolingo school)
- TikTok = canal #1 acquisition
- Tarifs adaptés : pass 3,99 € (pas 4,99), packs sparks 0,99-4,99 prio

### Budget mini + Claude Pro
- **Tu as Claude API via Pro ? Non, Pro ≠ API**. Pro = usage chat, pas API
- Pour vérif IA en prod, il faudra :
  - Option A : **Gemini Flash gratuit** (15 req/min free tier) → MVP only
  - Option B : **GPT-4o-mini API** ≈ 0,00015 €/image
  - Option C : **modèle local open-source** (Llama 3.2 Vision, Qwen2-VL) hébergé sur Hugging Face Spaces gratuit ou Replicate pay-per-use
  - Option D : prendre Claude API (Haiku 4.5) ≈ 0,001 €/image, le plus fiable
- → **Reco** : commencer Gemini Flash gratuit en MVP, switch Claude Haiku quand traction

### Toi+moi en dev
- Tu apprends en faisant (je suppose niveau intermédiaire)
- Stack à choisir simple + bien documentée
- Reco : **React Native + Expo** (le plus de tutos/IA support) + **Supabase** (auth+db+storage+realtime tout-en-un gratuit jusqu'à 50k MAU)
- → **stack 100% gratuit jusqu'à traction sérieuse**

### Rentabilité rapide
- Pass mensuel dès V1 obligatoire
- Pas perdre 6 mois en gratuit-only
- Mais : pas pay-to-win, pas pub agressive (cf cible jeunes = ferment vite l'app)

## Sur la compétition hebdo V1 ou V2

**Reco : V1, mais simplifiée.**

- Sans compet hebdo = juste un habit tracker → pas le différenciateur
- Avec compet hebdo = "rendez-vous" obligatoire, rétention forte
- V1 light : doubler XP le dimanche + classement spécial 24h, **pas de récompenses €** (juste badges/sparks) → coût zéro, légal simple
- V2 : ajouter récompenses partenaires quand audience prête
