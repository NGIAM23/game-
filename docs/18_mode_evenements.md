# Mode Évènements — Organisateur

## Concept validé
Toi (admin) + plus tard ambassadeurs / partenaires créent des **évènements physiques** où :
- Date + heure + zone géographique définie
- Participants s'inscrivent (avec KYC vérifié)
- Matchmaking automatique en équipes ou solo
- Liste de missions custom propres à l'événement
- Classement temps réel pendant l'event
- Récompenses à la fin (XP, badges exclusifs, lots partenaires)

✅ **Excellente idée.** C'est ce qui peut transformer l'app en mouvement local réel.

---

## Le module "Event Mode" — Fonctionnalités

### Côté admin / organisateur

**Création évènement**
- Nom : "Rassemblement LaVie — Parc de la Navale #1"
- Description
- Date / heure début / heure fin
- Zone : GPS + rayon (ex : 500m autour fontaine du parc)
- OU polygone dessiné sur carte (précision max)
- Capacité max participants
- Restrictions âge : tous / majeurs only / mineurs only / 16-25 / etc.
- Inscription : libre / sur invitation / liste validée
- Mode :
  - Solo (chacun pour soi)
  - Équipes random
  - Équipes choisies (équilibrées par niveau)
  - Capitaines (façon foot cour de récré)
- Type de classement :
  - Général
  - Par âge (mineurs vs majeurs séparés)
  - Par équipe
  - Multi-classements simultanés

**Création missions custom**
- Missions classiques de l'app (réutilisables)
- Missions **spécifiques événement** :
  - "Trouver le déchet caché code A1" (tu en as placé 10)
  - "Atteindre le checkpoint X"
  - "Photo avec le mascotte / l'organisateur"
  - "Quizz écolo sur le parc" (3 questions intégrées)
  - "Réunir 5 joueurs et faire selfie groupe"
- Validation : auto IA / manuelle organisateur / code à scanner
- Points custom (pas la même grille que XP normale)
- Ordre libre / séquentiel

**Setup zone (préparation IRL)**
- Tu places objets / QR codes / déchets cachés AVANT l'event
- L'app a un mode "Placer un objet ici" → scan position GPS + photo
- Tu génères des QR codes printables à mettre sur les checkpoints
- Liste exportable pour préparer ton terrain

**Sécurité événement (essentiel)**
- Champ "Personnel de sécurité présent : oui / non"
- Champ "Référent urgence" (toi + n° de tel)
- Bouton SOS spécifique pendant l'event → notif aux référents
- Geofence stricte : si user sort de zone = warning
- Zones interdites dessinables (route, plan d'eau dangereux)

### Côté participant

**Découverte**
- Onglet "Évènements" dans l'app
- Liste évènements à venir (filtré par ville/distance)
- Détail : carte, missions, récompenses, organisateur, sécurité
- Bouton "S'inscrire"

**Avant l'event**
- Rappel 24h avant + 1h avant
- Brief en notif : "Sois là à 9h, point d'accueil ici"
- KYC vérifié obligatoire (cf fichier 17)

**Pendant l'event**
- Mode "Event actif" dans l'app
- Vue carte avec :
  - Sa position
  - Zone autorisée
  - Checkpoints / missions à proximité
  - (Optionnel) positions équipiers
- Liste missions cochables
- Classement live (top 10 ou tous selon param)
- Chat event éphémère (modéré, supprimé après)
- Bouton SOS direct référent

**Après l'event**
- Classement final
- XP + badges crédités
- Photos / souvenirs (galerie event partagée si opt-in)
- Note de l'event (1-5)
- Notification "prochain event prévu le..."

## Workflow rdv mairie — la partie événements

### Le pitch événement

> Vous me donnez l'autorisation d'organiser **1 matinée tous les 2 mois** au Parc de la Navale, avec présence d'1-2 agents de police municipale, et je m'occupe de tout le reste : préparation, animation, sécurité interne, communication.
> En échange, la ville bénéficie :
> - D'un événement gratuit pour les habitants
> - D'une activité jeunesse non-numérique (paradoxe assumé)
> - D'une opération propreté visible (déchets ramassés)
> - D'une visibilité presse / réseaux
> - D'un partenariat innovant pionnier

### Ce que tu demandes à la mairie

1. **Autorisation occupation du parc** (formulaire standard, gratuit)
2. **Présence de la police municipale** (1-2 agents, 3h)
3. **Prêt de matériel** : tables pliantes, banderole, gobelets eau, sacs poubelle
4. **Communication ville** : 1 post sur réseaux mairie, 1 affiche office tourisme
5. **(Bonus)** Petit budget pour goodies/lots : 200-500 €

### Ce que tu apportes
1. Organisation complète
2. Communication app + réseaux
3. Mascotte / animation
4. Photos / vidéo post-event pour la ville
5. Bilan chiffré (participants, déchets ramassés, satisfaction)
6. Assurance Responsabilité Civile organisateur (50-100 €/event via MAIF/MACIF)

### Aspects légaux à anticiper

**Déclaration manifestation publique**
- Si <100 personnes ou private : pas obligatoire
- Si >100 ou voie publique : déclaration préfecture 3 jours avant
- Si très grosse : préfecture 1 mois

**Assurance RC organisateur**
- Obligatoire moralement, recommandée juridiquement
- ~50-100 €/event ou 200-400 €/an forfait

**Mineurs**
- Si présence mineurs non accompagnés : décharge parentale signée
- Encadrement : 1 adulte responsable / 10 mineurs (recommandé)

**Premiers secours**
- Idéalement 1 personne PSC1/SST sur place
- Trousse de secours
- N° d'urgence affiché

## Idées d'évènements concrets

### Format 1 — Le "Clean Up Challenge" (le + facile à vendre mairie)
- Matinée 9h-12h
- Mission : ramasser le + de déchets en équipes
- Photos avant/après
- Vainqueurs : récompense + mise en avant ville
- Mairie ADORE (propreté = priorité élus)

### Format 2 — Le "Sport Trail"
- Parcours type orientation
- Checkpoints à atteindre dans ordre libre
- Mix course + tâches mini
- Tous niveaux (marche acceptée)

### Format 3 — Le "Connaissance ville"
- Quizz géolocalisés sur monuments / histoire
- Découverte patrimoine
- Mairie + office tourisme partenaires

### Format 4 — Le "Bénévolat 1h"
- Partenariat asso locale
- 1h d'action bénévole + 2h de jeu
- Gros XP boost
- Asso gagne aide bénévole, app gagne crédibilité

### Format 5 — Le "Festival LaVie" (V2+, après succès)
- Journée entière
- Multi-stations
- Plusieurs centaines de joueurs
- Partenariats marques + foodtrucks
- Modèle économique : sponsors
