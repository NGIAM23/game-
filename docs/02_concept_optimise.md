# Concept optimisé

## Nom de travail
**LaVie** / **IRL** / **REAL XP** / **+1** / **Levelup**
→ tester noms courts, mémorables, traduisibles

## Pitch one-liner
> Le seul jeu où tu gagnes des niveaux **dans la vraie vie**, avec preuve.

## Positionnement unique
Pas un habit tracker. Un **jeu social compétitif** où la progression est **vérifiée**.

## Boucle de jeu (core loop)
1. Ouvrir l'app → voir tâches du jour
2. Faire la tâche IRL
3. Photo/vidéo preuve → IA valide → XP crédité
4. Niveau monte → rang monte → classement bouge
5. Streak / pass / récompenses → revenir demain

## Piliers (à garder)
- Niveaux quasi-infinis ✅
- Classement géolocalisé (ville/pays/monde) ✅ **= ton gros différenciateur**
- Rangs visuels (Bronze → Légende) ✅
- Pass mensuel ✅
- Compétition hebdo ✅ **= excellent pour rétention**
- Chat modéré ✅

## À ajouter / pousser

### Vérification IA (CRITIQUE)
- Photo + EXIF (date, géoloc) → anti-triche basique
- IA multimodale (Claude/GPT-4V/Gemini) qui décrit l'image et matche la tâche
- Détection deepfake / image IA
- Score de confiance → si bas, validation communautaire (3 users random valident)
- **Système de signalement** + perte XP si triche détectée

### Catégories de stats (au lieu d'un seul niveau)
- 💪 Corps (sport, nutrition, hygiène)
- 🧠 Esprit (lecture, apprentissage, projet)
- ❤️ Social (famille, amis, dates)
- 🤝 Altruisme (dons, civisme, écologie)
- 💼 Productivité (travail, ménage, finances)
- 🎨 Création (cuisine, art, hobby)

→ niveau global = moyenne pondérée
→ rangs séparés par stat possible

### Système de "Quête Vie"
Au-delà des tâches quotidiennes → objectifs long terme (3-6-12 mois)
- "Courir un 10km"
- "Lire 12 livres en 1 an"
- "Économiser X€"
→ XP énorme à la complétion, badge permanent

### Mode "Sans écran"
Une tâche meta : **fermer l'app** X heures → gagne XP passif
→ paradoxal mais aligné avec la mission "devenir meilleur"
→ argument marketing imbattable : "l'app qui veut que tu l'utilises moins"

### Mentor / Sage IA
Chat IA qui :
- propose des tâches adaptées à ton niveau/profil
- te coache sur stats faibles
- te rappelle ton "pourquoi"

### Cercle / Guilde
- groupes de 5-10 amis ou inconnus
- bonus XP collectif si tous actifs
- défis de groupe hebdo

## Ce qu'il faut SUPPRIMER ou repenser

- ❌ "Donner argent à SDF" → risque éthique énorme (exploitation pauvreté, photos non consenties)
  → remplacer par "Don associatif vérifié via reçu" ou "Acheter repas + don anonyme"
- ⚠️ "Habillé classe" → trop subjectif, IA va galérer, narcissique
- ⚠️ Preuve vidéo → lourd, batterie, stockage → **photo + métadonnées suffit 95% du temps**
- ⚠️ "Aller voter" → photo dans isoloir = ILLÉGAL dans plein de pays
  → remplacer par "scan carte d'électeur tamponnée" hors isoloir

## Public cible

- **Primaire** : 16-30 ans, gamers ouverts au self-improvement, fatigués de TikTok
- **Secondaire** : 30-45, parents, productivité, vouloir l'exemple
- **Géo prio** : France → francophonie → EU → monde

## Ton / Direction artistique

→ **PAS** RPG médiéval (déjà saturé)
→ Plutôt : minimal, premium, type Apple Fitness × Duolingo × BeReal
→ Couleurs : sobre + accents néon sur level-up
→ Animations satisfaisantes (haptic, son)
