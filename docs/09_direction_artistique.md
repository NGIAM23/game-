# Direction artistique — à trancher

3 directions possibles, choisis-en une.

## Option A — Premium minimal (style Apple/BeReal/Linear)

**Vibe** : sobre, propre, premium, presque luxe
**Couleurs** : noir/blanc + 1 accent fort (vert lime ou orange néon)
**Typo** : Inter / SF Pro / Söhne
**Animations** : subtiles, fluides, haptic
**Public** : 18-30 urbain, "gens cool", lifestyle, BeReal users
**Reco** : oui si tu veux marque premium long terme + B2B facile

**Risque** : froid, manque dopamine, pas assez fun pour ado 16-18

---

## Option B — Gamer/RPG moderne (style Solo Leveling/Duolingo)

**Vibe** : énergique, level-up satisfaisants, particules, son retro
**Couleurs** : sombres + néons (cyan, magenta, doré)
**Typo** : displays geometric, mono pour stats
**Animations** : explosives sur level-up, badges, rangs
**Public** : 14-22 gamers, anime fans, Solo Leveling generation
**Reco** : oui si tu veux **acquisition virale rapide jeune**

**Risque** : marque enfermée gaming, B2B impossible, vieillit mal

---

## Option C — Hybride sportif (style Strava/Nike Training/Apple Fitness)

**Vibe** : énergique mais pro, performance, data-driven
**Couleurs** : noir/anthracite + accent vif (rouge ou orange)
**Typo** : condensed bold (style sport)
**Animations** : type running app, graphs, courbes
**Public** : 18-35 actifs, self-improvers, fitness, productivité
**Reco** : oui si tu veux **équilibre acquisition jeune + crédibilité adulte**

**Risque** : un peu vu, pas autant viral que B

---

## Ma reco finale

Vu ta cible **16-25 priorité + élargissement 25-30** + **rentabilité rapide** + **B2B moyen terme** :

→ **Option C (Hybride sportif) avec touches d'Option B sur level-ups**

Pourquoi :
- Strava-like = sérieux, crédible → adultes paient + B2B possible
- Animations Solo-Leveling sur level-up = dopamine ado/jeune
- Couleurs sombres = TikTok-friendly (contenu viral)
- Évite piège RPG enfermant

**Style cible : "Strava rencontre Solo Leveling, motivé par Duolingo"**

→ Dis-moi A, B ou C (ou mix).
