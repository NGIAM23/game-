# Risques et éthique

## Risques légaux

### RGPD / privacy
- Photos = données personnelles → consentement explicite
- Géoloc = sensible → opt-in granulaire
- Mineurs → COPPA/RGPD-K, parental consent <15
- Hébergement EU obligatoire (Scaleway, OVH, AWS Paris)

### Gambling / loot box
- Récompenses random argent réel = régulé (Belgique interdit, France ANJ surveille)
- Solution : récompenses **déterministes** ou non-monétaires

### Compétitions à prix
- "Concours" = règlement légal à déposer (huissier en France)
- Conditions claires, transparence tirages
- Ou présenter comme "récompense de performance" pas "lot tirage"

### Photos publiques de tiers
- "SDF, ami, collègue" → droit à l'image
- ⚠️ NE JAMAIS afficher publiquement photos où apparaissent des tiers non consentants
- Solution : flou automatique visages + plaques + IA détecte tiers

## Risques éthiques

### Exploitation pauvreté
- "Donner au SDF + photo" → voyeurisme, instrumentalisation
- **À supprimer ou refonder** : preuve via don associatif numérique (reçu), pas photo personne

### Compétition toxique / burnout
- Classement = stress
- Solution :
  - Mode "perso" sans classement
  - Limite quotidienne XP (anti-grind)
  - Notifs "prends une pause"
  - Tâches de repos valorisées

### Validation IA biaisée
- IA peut discriminer (peau foncée mal détectée, etc.)
- Audit modèle régulier
- Toujours appel humain possible

### Vie privée tracking
- Tu sais tout : sport, repas, sorties, vote, sommeil
- → données extrêmement sensibles
- Encryption bout-en-bout idéale, sinon serveur
- Politique de transparence radicale

### Manipulation / addiction
- Les leviers que tu utilises = ceux de TikTok
- Mission "rendre meilleur" doit primer sur "rétention max"
- → cohérence du mode "Sans écran"
- Pas de notifs spammy

## Risques business

### Triche massive → perte de crédibilité
- Si users voient classement bidon → fuite
- Investir LOURD dans anti-triche dès jour 1

### Coûts IA explosent
- Croissance virale = facture API énorme
- Prévoir : modèle propriétaire fine-tuné mid-term
- Filtre rules-based en premier

### Saturation marché
- Beaucoup d'apps gamification existantes
- Tu dois ABSOLUMENT capitaliser sur le différenciateur "vérification + classement géo"

### Acquisition utilisateurs chère
- CAC mobile = 2-10 € / install
- Stratégie organique nécessaire :
  - TikTok / Reels créateurs lifestyle
  - "Challenge LaVie" viral
  - Partenariats influenceurs self-improvement
  - Référence "Bigslaay" → contacte-le pour partenariat early

## Mitigations transverses

- Charte éthique publique
- Comité de modération communauté
- Système d'appel pour décisions IA
- Mode "détox" forcé à l'inscription (recommande pauses)
- Transparence revenus & roadmap
