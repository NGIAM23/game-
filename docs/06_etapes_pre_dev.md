# Étapes pré-dev

## Avant de coder UNE ligne

### 1. Validation concept (2-4 semaines)
- Landing page simple ("rejoins la beta")
- Pub TikTok/Insta 50-200 € → mesurer CTR + signups
- Sondage 100 personnes cible → quelles tâches résonnent
- Test wording / nom / pitch

### 2. Branding + Identité
- Nom final (vérif dispo domain + trademark INPI/EUIPO)
- Logo
- Charte graphique
- Compte Insta/TikTok = teaser → audience pré-launch

### 3. Prototype papier / Figma
- Flows utilisateurs : onboarding, faire tâche, voir classement
- 10 écrans clés
- Faire tester à 5 personnes
- Itérer

### 4. MVP cadrage technique
- Stack pressentie :
  - Mobile : **React Native** ou **Flutter** (cross iOS/Android, 1 codebase)
  - Backend : Node.js / Python FastAPI
  - DB : PostgreSQL + Redis
  - Stockage photos : S3 / R2
  - IA vérif : Claude API / GPT-4V (start), modèle propre après
  - Auth : Clerk / Supabase Auth
  - Push : Firebase / OneSignal
  - Analytics : PostHog / Mixpanel
- Hébergement EU dès le départ

### 5. MVP scope (Lean)
**Inclus V1** :
- Auth
- 20 tâches du pool, 3/jour assignées
- Photo + vérif IA basique
- XP / niveau / 5 rangs
- Classement national simple
- Streak
- Pass mensuel (Stripe / Apple/Google In-App)
- Profil

**EXCLUS V1 (V2+)** :
- Cercles
- Compétition hebdo (V2)
- Marketplace récompenses (V3)
- B2B (V3+)
- Chat (V2)

### 6. Légal early
- Statut juridique (auto-entreprise → SASU si traction)
- CGU / Politique privacy (avocat ~500-1500 €)
- DPO si scale
- Trademark dépôt (~250 € INPI)

### 7. Financement
- Bootstrap possible si tu codes
- Sinon : BPI / French Tech / pré-seed 100-300k €
- Subventions tech : Bpifrance i-Lab
- Sans levée : <50k € pour MVP si dev solo

## Étapes une fois MVP prêt

1. Beta privée 100-500 users (1-2 mois)
2. Itération + bug fix + équilibrage XP
3. Soft launch France
4. Marketing organique (TikTok push)
5. Si signal positif → levée + équipe
6. Expansion EU
7. Version PC / web

## Métriques à viser

- D1 retention : >40%
- D7 retention : >20%
- D30 retention : >10%
- Conversion pass : 2-5%
- ARPU : 1-3 €/mois
- NPS : >50

## À faire MAINTENANT (cette semaine)

1. Réserver nom de domaine + handles réseaux
2. Lancer landing page (Carrd / Framer, 1h de boulot)
3. Créer compte Insta/TikTok teaser
4. Lister 100 idées de tâches → catégoriser
5. Faire ce sondage cible
6. Étudier Habitica/LifeUp 30 min chacun → noter ce qui marche / pas
7. Contacter Bigslaay pour partenariat early ?
